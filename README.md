# Darts Counter 🎯

A browser-based darts scoring app built with **HTML, CSS, and vanilla JavaScript**.  
It allows adding multiple players, selecting game modes (301, 501, 420, 666), and tracks scores, averages, and last throws automatically.

## 🎮 Features
- Add any number of players
- Choose between 301, 501, 420, or 666 game modes
- Real-time score tracking and average calculation
- Undo functionality and win detection
- Responsive dark-themed UI
- Option to switch between numeric pad and dartboard-style input

## 🧠 Technologies
- **HTML5** for structure  
- **CSS3** for responsive UI  
- **Vanilla JavaScript** for all logic and interactivity

## 🚀 How to Run
1. Download or clone this repository  
2. Open `dartsCounter2.html` in your browser  
3. Add players, pick a mode, and start throwing!

This project was created to practice **DOM manipulation**, **game logic**, and **state management** in JavaScript.
